## 🚀 Featured Projects

### 📒 [KhataBook / Digital Ledger](https://github.com/kalviumcommunity/S116-0726-CoreSync-FullStack-Nextjs-PostgreSQL-Prisma-KhataBook_DigiLedger)
A digital ledger application that digitizes traditional shop ledgers, letting users record transactions and track customer balances in one place.
- **Stack:** React.js, Next.js, Node.js, Express.js, PostgreSQL, Prisma, REST APIs, JWT, bcrypt
- **Highlights:** relational databases, SQL joins, running-balance logic, pagination

### 🏠 [HomeVault](https://github.com/yashwardhan-chaudhari/HomeVault)
A web application that helps users organize household items, manage storage locations, and quickly find their belongings.
- **Stack:** React.js, Node.js, Express.js, JWT, REST APIs
- **Highlights:** user authentication, CRUD operations, map-based location selection, photo/video handling

### ⚡ [FlashAds](https://github.com/yashwardhan-chaudhari/FlashAds)
A web application for creating, managing, and displaying advertisements, giving small businesses a quick way to publish and browse ads.
- **Stack:** React.js, Node.js, Express.js, MongoDB, REST APIs, JWT
- **Highlights:** API design, authentication, frontend-backend integration
